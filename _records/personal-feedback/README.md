# Primary-reader feedback records

This directory stores only feedback that George explicitly approves for editorial learning. A record covers one six-story edition and uses:

- most_useful
- useful
- neutral
- not_useful

Optional reason tags are book_or_course, consulting, tool_worth_testing, important_emerging_concept, too_technical, too_promotional, and not_relevant.

Every record must validate against _contracts/v1/personal-feedback.schema.json, include the edition’s exact 2/2/2 story allocation, contain no personal identifiers or browsing history, and be approved for learning. Public anonymous ratings are stored only as aggregate counters and never copied into this directory as if they were George’s feedback.
