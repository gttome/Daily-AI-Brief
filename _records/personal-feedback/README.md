# Primary-reader feedback records

This directory is an optional fallback for richer feedback that George explicitly approves for editorial learning. Routine feedback now comes from the compact anonymous buttons beneath every story. A manual record covers one six-story edition and uses:

- most_useful
- useful
- neutral
- not_useful

Optional reason tags are book_or_course, consulting, tool_worth_testing, important_emerging_concept, too_technical, too_promotional, and not_relevant.

Every manual record must validate against _contracts/v1/personal-feedback.schema.json, include the edition’s exact 2/2/2 story allocation, contain no personal identifiers or browsing history, and be approved for learning. Anonymous inline ratings stay in aggregate analytics. A complete inline aggregate supersedes a manual record for the same date to prevent double-counting.
