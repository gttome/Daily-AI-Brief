# Nightly Readiness Reports

This non-production branch stores the Daily Generative AI Brief nightly structural readiness reports.

- It is **not** a publication branch.
- It must never be merged into `main` as part of normal nightly readiness reporting.
- Reports are inspection-only evidence generated by the 9:00 PM America/Chicago readiness audit.
- The audit must not invoke ChatGPT Work, Codex, paid APIs, editorial research, image generation, media research, or a test Brief.

Reports are stored as:

`nightly-readiness/Daily_AI_Brief_Nightly_Readiness_YYYY-MM-DD.md`

The GitHub readiness-notification issue links to the dated report each night.
