# NVIDIA packages verified DOCA expertise into reusable agent skills

**Technical AI Engineering · Agent Skills**  
**Date:** October 1, 2026 · **Estimated source read:** 5 min

![Application task entering a maintained DOCA Skill package and passing through verified API, hardware, build, and preflight controls before a validated BlueField application path.]({{ '/rehearsals/pre-oct3-20261002-r1/images/dab-rehearsal-2026-10-02-m01-2.png' | relative_url }})

NVIDIA describes DOCA skills as machine-readable domain knowledge that packages verified API signatures, hardware requirements, build constraints, examples, and preflight checks for infrastructure development.

**Why it matters:** A reusable skill turns fragile prompt context into maintained technical knowledge that can be checked before an agent proposes or executes infrastructure work.
