**Summary:** Salesforce’s September 16 article describes long-horizon agents working alongside users toward a goal over time and adapting to changing circumstances. Its introduction contrasts this with a request followed by a single response.

**Why it matters:** When planning an ongoing agent workflow, define the enduring goal and the circumstances that should prompt review. That is practical design guidance, not a verified product capability checklist.
